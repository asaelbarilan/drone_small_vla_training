# D212 evidence matrix

Search date:2026-10-10. 31 candidates;27 retained works (25 primary papers, one author implementation article, one official API document). Inspection is scoped to the passages listed, not every page. No external result was reproduced. Unknowns are explicit.

| ID / source | Inspected evidence | Local implication | Transfer limit |
|---|---|---|---|
| [E01: Proximal Policy Optimization Algorithms](https://arxiv.org/pdf/1707.06347) (2017) | Clipped policy ratios limit incentives for large updates; clipping is not a hard guarantee on all policy changes. | Defines the optimizer contract, not our reward or flight success. | Original low-dimensional/game experiments do not establish VLA hyperparameters. |
| [E02: High-Dimensional Continuous Control Using Generalized Advantage Estimation](https://arxiv.org/html/1506.02438v6) (2016) | GAE combines temporally ordered TD residuals; inaccurate values introduce bias. | Require hand-computed GAE fixtures and valid next-state values. | Locomotion setting, not action-token drone control; first preprint 2015. |
| [E03: Implementation Matters in Deep Policy Gradients: A Case Study on PPO and TRPO](https://arxiv.org/html/2005.12729v1) (2020) | Normalization, initialization and optimizer details materially affect PPO outcomes in controlled ablations. | Test the implementation before attributing outcomes to PPO. | Only four implementation choices fully crossed; do not copy MLP initialization onto a pretrained VLA. |
| [E04: What Matters In On-Policy Reinforcement Learning? A Large-Scale Empirical Study](https://arxiv.org/html/2006.05990v1) (2020) | Architecture and normalization choices interact with tasks; a beneficial choice on one environment can hurt another. | Treat defaults as pilot hypotheses and log every normalization. | Continuous MLP policies differ from categorical pretrained tokens; preprint year used. |
| [E05: Time Limits in Reinforcement Learning](https://proceedings.mlr.press/v80/pardo18a/pardo18a.pdf) (2018) | Intrinsic deadlines and external collection cutoffs require different value targets. | Separate termination, truncation and infrastructure failures. | A longer limit alone does not establish task completion. |
| [E06: A Reduction of Imitation Learning and Structured Prediction to No-Regret Online Learning](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf) (2011) | Imitation guarantees depend on an expert and loss assumptions; a geometric heuristic is not automatically that expert. | Explains why collecting student states does not validate our corrective actions. | Theory does not certify any particular synthetic label generator. |
| [E07: What Can RL Bring to VLA Generalization? An Empirical Study](https://arxiv.org/html/2505.19789v2) (2025) | PPO outperformed compared GRPO/DPO variants in this setup; shared critic and one epoch were effective. | Closest actor-critic recipe, but not evidence of universal PPO superiority. | Two seeds; manipulation; vision robustness did not clearly improve over SFT. |
| [E08: SimpleVLA-RL: Scaling VLA Training via Reinforcement Learning](https://arxiv.org/html/2509.09674v1) (2025) | GRPO can work for VLAs; equal-reward groups give no relative learning signal and exploration matters. | Counterexample to dismissing GRPO; requires reliable binary success and repeated rollouts. | Distributed manipulation workflow; first preprint used, repository labels ICLR 2026. |
| [E09: Interactive Post-Training for Vision-Language-Action Models](https://arxiv.org/html/2505.17016v1) (2025) | RIPT uses leave-one-out advantages and rejects all-zero groups; improvement depends on useful sampled outcomes. | Alternative if critic fitting fails and repeated rollouts have signal. | Not identical to standard GRPO; rejection loop needs an explicit local cost ceiling. |
| [E10: VLA-RL: Towards Masterful and General Robotic Manipulation with Scalable Reinforcement Learning](https://arxiv.org/html/2505.18719v1) (2025) | PPO uses sequence likelihoods; critic warmup and learning-rate choice affect stability in ablations. | Guides critic gate and exact sequence likelihood tests. | Separate learned process reward and distributed infrastructure are substantial additions; do not copy unvalidated reward labels. |
| [E11: ConRFT: A Reinforced Fine-tuning Method for VLA Models via Consistency Policy](https://arxiv.org/html/2502.05450v2) (2025) | Offline BC/Q initialization is followed by online learning with human intervention and replay. | Shows effective RL may rely on extra feedback infrastructure. | Consistency action head and human interventions make it unsuitable as a drop-in token PPO script. |
| [E12: WorldVLN: Autoregressive World Action Model for Aerial Vision-Language Navigation](https://arxiv.org/html/2605.15964v1) (2026) | Aerial RL combines world-action modeling with action-aware GRPO; rewards include reference and endpoint terms. | Domain-relevant comparison; inspect semantics before borrowing endpoint reward. | Different backbone and supervision; endpoint reward does not independently solve our closed-loop orbit ambiguity. |
| [E13: RLinf: Flexible and Efficient Large-scale Reinforcement Learning via Macro-to-Micro Flow Transformation](https://arxiv.org/html/2509.15965v1) (2025) | Worker placement, staged resource use, failure propagation and timing are integral to RL system performance. | Borrow stage boundaries and profiling; evaluate framework port separately. | Cluster speedups cannot predict Windows L4 throughput. |
| [E14: RLinf-Co: Reinforcement Learning-Based Sim-Real Co-Training for VLA Models](https://arxiv.org/html/2602.12628v1) (2026) | Auxiliary supervised data during simulator RL is used to preserve real-world capabilities. | Motivates independently checked anchors and explicit retention evaluation. | Does not prove a particular anchor weight prevents our box regression. |
| [E15: UAV-Flow Colosseo: A Real-World Benchmark for Flying-on-a-Word UAV Imitation Learning](https://arxiv.org/html/2505.15725v1) (2025) | Recorded data are aligned at 5Hz; paper success uses semantic inspection, with nDTW as a separate trajectory measure. | Distinguishes recording cadence and benchmark semantics from our endpoint proxy. | Current project endpoint scores are not interchangeable with paper semantic success; no physical validation of our teleport evaluator. |
| [E16: LIBERO: A Benchmark for Lifelong Robot Learning](https://arxiv.org/html/2306.03310v1) (2023) | Defines task goals separately from demonstrations; loss and execution success need not track each other. | Separate completion predicate, policy training and regression suites. | Manipulation benchmark; early paper title differs from later repository title. |
| [E17: RoboTwin 2.0: A Scalable Data Generator and Benchmark with Strong Domain Randomization for Robust Bimanual Robotic Manipulation](https://arxiv.org/html/2506.18088v2) (2025) | Synthetic expert generation uses simulator execution checks, not merely plausible generated commands. | Supports validating synthetic targets through independent execution and semantic review. | Bimanual domain; generated data are not automatically trustworthy for UAVs. |
| [E18: What Are We Actually Benchmarking in Robot Manipulation?](https://arxiv.org/html/2606.04233v1) (2026) | Shortcut-solvable tasks and aggregate-only reporting weaken capability claims. | Stationary/wrong-object controls and per-task paired reporting. | Recent preprint; audit conclusions are protocol-specific, not proof every high-scoring model lacks capability. |
| [E19: Deep Reinforcement Learning at the Edge of the Statistical Precipice](https://arxiv.org/html/2108.13264v3) (2021) | Few-run uncertainty and checkpoint-selection protocols can change apparent rankings. | Pre-register evaluation and distinguish one-seed pilot from replicated result. | Task bootstrap alone cannot estimate training-seed variability. |
| [E20: Deep Reinforcement Learning That Matters](https://arxiv.org/html/1709.06560v3) (2018) | Architecture and optimization choices interact; reported performance changes with implementations and seeds. | Record configuration and include matched baselines. | AAAI 2018; preprint 2017; not a direct VLA recipe. |
| [E21: Empirical Design in Reinforcement Learning](https://jmlr.org/papers/volume25/23-0183/23-0183.pdf) (2024) | Fixed episode counts can hide different interaction costs; design comparisons around the scientific question. | Budget actions, calls, wall time and updates separately. | Methodological evidence, not an estimate of required UAV training hours. |
| [E22: DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models](https://arxiv.org/html/2402.03300v3) (2024) | GRPO replaces a learned value baseline with statistics over grouped outputs. | Clarifies what GRPO removes and the cost of group sampling. | Text outputs do not share our interactive stochastic state transitions. |
| [E23: Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware](https://arxiv.org/html/2304.13705v1) (2023) | Action chunking and observation updates are design choices; excessively open-loop execution loses reactivity. | Keep photo frequency, action displacement and replanning cadence separate. | Joint-target control at 50Hz does not prescribe meters per UAV action. |
| [E24: Fine-Tuning Vision-Language-Action Models: Optimizing Speed and Success](https://arxiv.org/html/2502.19645v1) (2025) | Parallel decoding and continuous heads alter throughput and likelihood structure. | Do not substitute a deterministic action head into categorical PPO without a new probability model. | Architecture migration would confound the immediate RL experiment. |
| [E25: OpenVLA: An Open-Source Vision-Language-Action Model](https://arxiv.org/html/2406.09246v1) (2024) | Discrete action tokens use dataset-derived bin bounds; input/output consistency and data mixture matter. | Audit tokenizer bounds/units and preserve the existing representation in the first pilot. | Different base VLM and robot embodiment; no ready-made checkpoint for our Qwen drone. |
| [E26: The 37 Implementation Details of Proximal Policy Optimization](https://iclr-blog-track.github.io/2022/03/25/ppo-implementation-details/) (2022) | Reference implementations include choices and historical quirks not stated in the PPO equation. | Use as test checklist, not blindly copied production code. | Author implementation article, not an independent primary experiment paper in this ledger. |
| [E27: Gymnasium: Handling Time Limits](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/) (2026) | The environment API separates termination from truncation for correct bootstrapping. | Define this distinction explicitly in our rollout schema. | Documentation accessed 2026; year is access year, not original publication. |
